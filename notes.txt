React Course Guidelines (basic)

1. create project folder
2. open project folder in vscode
3. install create-vite (command: npm install create-vite@<version number>)
4. run create-vite (command: create-vite), select :
    a. enter project name
    b. select React framework
    c. select Javascript variant
5. create-vite will create an empty React project in target directory
6. run npm install inside project directory, this command will install all packages listed inside package.json
   along with all the dependecies
7. run npm run dev to host created project locally

Node

1. install node js
2. node = enable execution of Javascript outside of browser
3. npm install <package name> = use to install package (collection of library; Example supersimpledev)
4. search for packages in npm website (https://www.npmjs.com/)
